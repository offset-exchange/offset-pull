OFFSET PULL — Security & Privacy Sheet

For IT and compliance review · 2026-10-05 · Offset Exchange LLC

What it is

A desktop application (Windows and macOS) that opens official county assessor and treasurer websites for an address the user types, and saves the pages those websites return as PDF files in the user's own folder. It replaces the manual steps of looking up a property tax sheet by hand.

Data handling

ItemWhere it goes
Addresses the user typesU.S. Census Bureau geocoder; OpenStreetMap Nominatim (once per Pull); the county's own website. Not sent to Offset Exchange.
Saved PDFs and historyStay on the user's computer only.
License key / ID and app versionGumroad license check and Offset Exchange's update feed (static file).
Borrower / customer dataNever requested, never collected. The app needs only a property address.
Passwords, loginsNone. The app never logs in anywhere and never bypasses a captcha or access control.

Built-in protections

  • County pages run in isolated browser views with Node.js turned off and no bridge to the computer: they cannot read or write the computer's files, and requests for camera, microphone or location are refused.
  • Any file a website tries to download is blocked and the user is told.
  • Connections use HTTPS, browser web security stays on, and insecure (mixed) content is blocked.
  • County fixes install only if they carry Offset Exchange's Ed25519 digital signature and a matching SHA-256 hash — a tampered or fake update is refused.
  • License keys are digitally signed, bound to one computer, and can be revoked remotely.
  • No admin rights, drivers, browser extensions or background services are installed. Removing the app removes it completely.
  • The app's code is obfuscated and compiled to protect it from tampering.
